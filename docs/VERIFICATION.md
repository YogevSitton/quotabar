# Verification status

This file records what has been checked against live provider accounts, what has only been compiled or tested with synthetic fixtures, and what remains unverified. It is the place for dated verification notes; keep the README focused on behavior.

All 18 samples advanced their matching cache timestamps, with zero model cost/API duration and empty model usage. Only sanitized timing and outcomes were retained. This small sequential trial does not establish a safe server quota or guarantee future absence of rate limiting. The unchanged installed app was restored after the trial.

Independent static review covered the fixed request, private configuration, helper pin/signature, process boundaries, authentication, request reservations and group/freshness handling.
