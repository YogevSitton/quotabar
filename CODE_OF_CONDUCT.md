# Code of Conduct

QuotaBar is a small project and we want it to stay a friendly place to ask questions, report problems and contribute, whatever your experience level or background.

## What we expect

- Be respectful and patient, especially with newcomers and people whose first language is not English.
- Assume good intent, and critique ideas and code, not people.
- Accept that the maintainer makes the final call on scope and design, and that "not right now" is a valid answer.
- Respect privacy: never post someone else's personal data, account details or private messages.

## What is not okay

Harassment, insults, discriminatory jokes or language, personal or political attacks, sexualized content, trolling, and deliberately sharing someone else's private information.

## Reporting

If someone's behavior bothers you, contact the maintainer privately through the contact details on their [GitHub profile](https://github.com/YogevSitton), or use GitHub's **Report content** option. Reports are kept confidential.

The maintainer may edit or remove comments, close issues or pull requests, and block people from the repository when this code is not respected. This code applies in all project spaces: issues, pull requests, discussions and reviews.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
